# 🚀 GEAR Mini-Project: AI Agent with Vertex AI

## 📌 Overview

Built a conversational AI agent using Google Cloud Vertex AI (Agent Platform) and Gemini. The project demonstrates how to create and interact with an AI agent directly from Google Cloud using Python.

## 🛠️ Technologies Used

- Google Cloud
- Vertex AI (Agent Platform)
- Gemini
- Python
- Google Cloud Shell

## ⚙️ Implementation

1. Enabled the Vertex AI (Agent Platform) API
2. Opened Google Cloud Shell
3. Installed the required Python SDK
4. Created the AI agent using Gemini
5. Tested the agent with conversational prompts
